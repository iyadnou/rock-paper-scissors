# Rock Paper Scissors

A simple Rock, Paper, Scissors game against the computer in the terminal.

This is a small entry-level project I made while learning Python.

## What it does

- You type Rock, Paper or Scissors
- The computer picks one at random
- The script tells you who won, or if it's a draw
- Invalid choices are rejected

## Requirements

- Python 3

## Run

```
python3 main.py
```
